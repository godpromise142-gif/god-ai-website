GOD AI WEBSITE
==============

Files:
- index.html
- style.css
- privacy.html
- downloads/god-ai.apk  <-- put your final APK here

HOW TO PUBLISH:
1. Put the final APK inside the downloads folder and name it god-ai.apk.
2. Upload the whole folder to your web hosting.
3. Your Download APK button will point to /downloads/god-ai.apk.
4. Before public launch, replace the placeholder privacy policy with the real one.

IMPORTANT:
Do not put your Gemini API key on the website.
Do not publish debug builds containing secrets.
Use a properly signed release APK for public distribution.
